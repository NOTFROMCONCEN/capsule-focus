# 胶囊专注 · 番茄钟 × 呼吸训练（灵动胶囊）

番茄钟与呼吸训练的结合体，运行状态实时显示在荣耀灵动胶囊上
（Android 16 Live Updates / promoted ongoing notifications，方案与 [Kelivo](https://github.com/chevey339/kelivo) 相同）。

## 功能

**番茄钟**
- 专注 15 / 25 / 45 分钟，胶囊上显示**原生倒计时**（chronometer countdown）
- 休息方式可选：普通休息 5 分钟，或 **呼吸放松 ≈5 分钟**（两种模式的结合点）
- 通知带 暂停 / 跳过 / 结束 按钮；阶段切换有声音+振动提醒
- 无限循环，直到手动结束

**胶囊样式（v1.2.0 打磨）**
- 小图标重绘为斜切药胶囊剪影，状态栏小尺寸下轮廓清晰
- 通知统一品牌红强调色（深浅色主题各取一档，胶囊圆点/经典进度条取色）
- 进度条设 tracker 图标：胶囊剪影骑在进度头上随进度逐秒移动
  （API 36 `ProgressStyle.setProgressTrackerIcon`，配送类实时通知同款）
- 标题带 🍅/☕/🌿 锚点，正文含剩余时间，胶囊与下拉通知信息一致

**呼吸训练**
- 节奏：4-7-8 放松 / 4-4-4-4 盒式，轮数 4 / 8 / 12
- 胶囊上用**多段彩色进度条**表达一轮节奏：
  吸气=蓝、屏息=青、呼气=绿、屏息=黄，进度逐秒扫过整轮
- 文字实时显示 "第 3/8 轮 · 吸气 4s"

**历史记录**（v1.1.0）
- 会话结束（手动结束 / 呼吸自然完成 / FGS 超时兜底）自动落一条：
  类型、开始时间、实际进行时长（暂停不计时）、完成番茄数 / 轮数、休息方式
- 首页「历史记录」页：累计统计（🍅 总数、专注总时长、呼吸总轮数、连续天数）
  + 按天分组（今天 / 昨天 / 日期）的会话列表
- 长按删单条，右上角「清空」删全部；记录以 JSON 存本地，上限 500 条

**快捷开始与激励（v1.3.0）**
- 下拉快捷设置磁贴「开始专注」：一键以上次配置开始番茄钟（会话中/无通知权限时退化为打开应用）
- 长按桌面图标 shortcuts：开始专注 / 呼吸训练
- 运行页呼吸动画：随阶段胀缩的节奏圆（吸气放大、屏息停住、呼气缩小，暂停冻结）
- 每日目标：点顶栏「今日 🍅 N/M」设置（1–50），达成后变绿
- 历史页新增「每日番茄」柱状图：最近 7/30 天切换，今天高亮，目标虚线参考

**自定义与专注增强（v1.4.0）**
- 专注时长/呼吸节奏自定义：chip 里选「自定义」弹数字输入
  （专注 5–180 分钟；呼吸四段秒数 0–60，屏息可为 0 即跳过）
- 普通休息时长可改（1–60 分钟），呼吸休息轮数按时长自动算
- 长休息：每 N 个番茄自动进 M 分钟长休息（默认关，通知显示 🛋）
- 专注白噪音：白/粉/棕三色实时合成（AudioTrack，不占体积），
  仅专注阶段播放，休息/呼吸自动静音
- 摸鱼检测：统计专注期间切走应用的次数（需授权「使用情况访问」，
  排除系统 UI），运行页实时显示，计入历史
- 呼吸引导振动：阶段切换轻振动一次，闭眼可跟节奏
- 待办清单：任务打勾/删除；点 ▶ 以该任务开始番茄钟，
  任务名上胶囊、入历史
- 历史页新增「时段分析」：按早晨/上午/午后/下午/晚上/深夜
  分桶统计番茄产出，指出最出番茄的时段

**MD 分栏界面（v1.5.0）**
- 主界面重构为四分栏：专注 / 待办 / 统计 / 设置
- 底部导航 + 右侧独立「开始」FAB；导航样式可在设置切换：
  「悬浮」= 悬浮胶囊卡（28dp 圆角，选中项胶囊色块高亮），
  「常规」= 铺满底部的通栏导航，FAB 浮于其上方
- 历史/统计从独立页面并入「统计」栏（原 HistoryActivity 移除）
- 设置栏集中：每日目标入口、通知/实时通知设置、版本、状态与日志排障
- 会话进行中隐藏整个主界面与导航，全屏显示运行页

**时间戳（v1.6.0）**
- 新增第 5 个分栏「时间戳」：记录现实世界操作的时间+备注
  （如拔掉某网络设备的接口、重启 AP），随手记、事后可查
- 快速记录：输入备注（可留空）→「记录」落一条当前时间，按天分组（今天/昨天/日期）
- 补记/编辑：长按条目改备注，点时间行选日期+时间补记实际发生时刻，或删除该条
- 导出：右上角「导出」把全部记录按时间正序「yyyy-MM-dd HH:mm 备注」复制进剪贴板，
  方便贴进工单/运维日志；「清空」二次确认后全删
- 记录独立存储（SharedPreferences JSON），上限 500 条，与会话历史互不影响

**保活**（真实可用的关键）
- 会话期间运行 `dataSync` 前台服务 + PARTIAL_WAKE_LOCK（Kelivo 同款），锁屏不中断
- Android 15+ 的 6 小时 FGS 上限有 `onTimeout` 兜底处理

## 构建

```bash
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

> 工程不要放在含中文/非 ASCII 字符的路径下，Windows 上 AGP 会拒绝构建。

## 在荣耀手机上使用

1. 安装 APK，打开，授予**通知权限**；
2. **重点：实时通知授权按包名单独生效**——点「打开系统"实时通知 / 灵动岛"设置页」，
   把本应用的开关打开（设置 → 通知和状态栏 → 灵动胶囊 里对应"胶囊专注"的那一项）。
   包名自 v1.0.0 起固定为 `app.capsulefocus`，此前装过 `com.demo.capsulefocus`
   旧包的可以卸载，旧授权对它无效；今后升级不再需要重新授权；
3. 点「开始呼吸训练」最直观：胶囊出现彩色节奏条，逐秒推进；
4. 或点「开始番茄钟」：胶囊显示倒计时，锁屏、切走都在；
5. 应用内状态区会显示 `FLAG_PROMOTED_ONGOING` 检测结果，确认是否真的上了胶囊。

## 已知边界

- 需要设备基于 Android 16（API 36）且 ROM 支持实时通知；
- 通知按钮最多 3 个（暂停/跳过/结束），是通知 Action 的系统上限；
- 呼吸的逐秒刷新和会话期 WakeLock 有少量电量开销，属预期行为；
- 历史记录在会话结束时写入：进行中被系统强杀/崩溃的那次会话不会入史；
  进行不足 1 分钟且无任何成果（0 番茄 0 轮）的秒停会话同样不入史。
