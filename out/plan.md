# 胶囊专注 v1.5.0 · MD 分栏界面重构 设计规格

本任务为 Android 原生应用（Kotlin）UI 重构，非视频复刻；无源视频，故仅有 [S] 静态可观察项，无 [D] 动态项。

[S1] 主界面为四分栏结构：专注 / 待办 / 统计 / 设置，同一时刻仅显示一栏
[S2] 底部导航为悬浮胶囊卡（28dp 圆角，surface_container 底色，4dp 投影），内含 4 个等宽导航项（图标 24dp + 11sp 标签）
[S3] 选中的导航项带 18dp 圆角胶囊色块（secondary_container #F3D9D5，深色 #4A221E），图标与文字转为 on_secondary_container；未选中为 dim 色
[S4] 导航右侧为独立 FAB（56dp，primary #E63328 底，白色播放图标），任意分栏可点，点击即按当前配置开始会话
[S5] 顶栏常驻：左侧 6×26dp 红色标记 +「胶囊专注」22sp 标题，右侧「今日 🍅 N/M」13sp 计数（达成变绿 #2E7D32）
[S6] 专注栏含：双模式卡片、专注时长 chips（15/25/45/自定义）、休息方式 chips、休息时长入口、长休息/白噪音/摸鱼检测三个开关行、56dp 主按钮；呼吸模式切换为节奏/轮数 chips + 引导振动开关
[S7] 待办栏为单卡片：输入框 + 添加按钮 + 任务行（勾选划线 / ▶ 开始专注 / ✕ 删除）
[S8] 统计栏含：清空按钮、累计卡、7/30 天每日番茄柱状图（140dp 高，目标虚线）、时段分析六桶横条、按天分组（今天/昨天/M月d日）的会话列表
[S9] 设置栏含：每日目标入口（点按弹 1–50 输入框）、实时通知设置、通知设置、版本号 v1.5.0、状态与日志排障区
[S10] 会话进行中：整个主界面（含底部导航与 FAB）隐藏，显示运行页（呼吸时为 200dp 胀缩圆）；回到空闲态恢复分栏
[S11] 根布局 fitsSystemWindows，内容避开状态栏与手势条；深浅色主题各自取色
